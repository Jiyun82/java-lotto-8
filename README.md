# java-lotto-precourse
# 로또
구입 금액을 입력하면 자동으로 로또를 발행하는 프로그램이다. <br/>
로또 발행 후, 당첨 번호와 보너스 번호를 입력 받는다. <br/>
발행된 로또를 당첨 번호와 비교하여 당첨 내역과 수익률을 출력한다.

## 구현할 기능
### 로또 구입 금액 입력
- [ ] 로또 구입 금액을 입력 받는다.
- [ ] 입력값이 양의 정수가 아닐 경우 예외 처리한다.
- [ ] 1000원 단위로 받고 나누어 떨어지지 않는 경우 예외 처리한다.
### 로또 발행
- [ ] 구입 금액에 해당하는 만큼 로또를 발행한다.
- [ ] 발행한 로또의 수량 및 번호를 오름차순으로 출력한다.
### 당첨 번호 입력
- [ ] 당첨 번호를 입력받는다. 번호는 쉼표를 기준으로 구분한다.
- [ ] 입력값이 숫자가 아닐 경우 예외 처리한다.
- [ ] 숫자의 범위가 1~45를 벗어날 경우 예외 처리한다.
- [ ] 입력된 숫자가 6개가 아닐 경우 예외 처리한다.
### 보너스 번호 입력
- [ ] 보너스 번호를 입력 받는다.
- [ ] 입력값이 숫자가 아닐 경우 예외 처리한다.
- [ ] 숫자의 범위가 1~45를 벗어날 경우 예외 처리한다.
### 당첨 결과 확인
- [ ] 당첨 여부를 확인하여 출력한다.
- [ ] 수익률을 계산하여 출력한다.

## 실행 결과 예시
```
구입금액을 입력해 주세요.
8000

8개를 구매했습니다.
[8, 21, 23, 41, 42, 43] 
[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
[1, 8, 11, 31, 41, 42] 
[13, 14, 16, 38, 42, 45] 
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]

당첨 번호를 입력해 주세요.
1,2,3,4,5,6

보너스 번호를 입력해 주세요.
7

당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
```
